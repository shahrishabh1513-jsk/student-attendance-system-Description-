## 📖 About

A lightweight, fully client-side **attendance app for faculty**. Everything runs in the browser with **HTML, CSS & JavaScript** — data is stored locally, so it works offline once loaded. Mark attendance in one tap, then review, print, or share reports as **Image, PDF, or Excel**.

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:11998E,100:38EF7D&height=3&section=header"/>

## ✨ Features

- 🔐 Simple faculty login
- 🗓️ Weekly timetable with Lab/Theory & batch support
- ✅ One-tap Present/Absent marking with auto-save
- 📊 Reports — view, edit, print & filter past sessions
- 📤 Export & share as Image / PDF / Excel
- 📱 Fully responsive on mobile & desktop

## 🚀 Getting Started

```bash
git clone https://github.com/shahrishabh1513-jsk/student-attendance-system-Description-.git
cd student-attendance-system-Description-
python -m http.server 8000
```

Then open `http://localhost:8000` — or just try the **[live demo](https://bscit-attendance.netlify.app/)**.
